# شاه‌مات — شطرنج سه‌بعدی در مرورگر

این پروژه یک بازی‌ی شطرنج گرافیکی، فارسی و واکنش‌گرا است که **بدون نصب برنامه‌نویسی، بدون گیت و بدون ساخت حساب گیت‌هاب** هم اجرا می‌شود. مهره‌ها با مدل‌های SVG سایه‌پردازی‌شده، صفحه‌ی چوبی با عمق سه‌بعدی، نورپردازی، ساعت بازی، دفتر حرکات و افکت‌های تعاملی طراحی شده‌اند.

> اگر فقط می‌خواهید بازی کنید، کافی است فایل `index.html` را باز کنید؛ هیچ مرحله‌ی فنی دیگری لازم نیست.

---

## چه چیزهایی آماده است؟

- صفحه‌ی شطرنج با ظاهر سه‌بعدی، قاب چوبی، سایه، نور زمردی و حالت نور کهربایی
- مهره‌های شاه، وزیر، رخ، فیل، اسب و پیاده با مدل SVG و پرداخت فلزی/عاجی
- بازی دونفره روی یک دستگاه؛ نوبت سفید و سیاه خودکار عوض می‌شود
- نمایش خانه‌های مجاز، انتخاب مهره، آخرین حرکت، کیش و وضعیت دو شاه
- قوانین اصلی: حرکت قانونی مهره‌ها، کیش، کیش‌ومات، پات، قلعه‌رفتن، آن‌پاسان و ارتقای پیاده
- پنجره‌ی انتخاب وزیر/رخ/فیل/اسب هنگام رسیدن پیاده به انتهای صفحه
- ساعت ۱۰ دقیقه‌ای برای هر بازیکن، بازگشت یک حرکت، چرخش صفحه، حالت تمرکز و راهنمای حرکت
- دفتر حرکات و دکمه‌ی کپی‌کردن PGN
- طراحی مناسب رایانه، تبلت و موبایل

---

## راه‌اندازی خیلی ساده (پیشنهادی برای کسی که برنامه‌نویسی بلد نیست)

### روش ۱: بازکردن مستقیم بازی — بدون نصب هیچ چیز

1. پوشه‌ای را که فایل‌های این پروژه در آن هستند باز کنید.
2. فایل **`index.html`** را پیدا کنید. آیکن آن معمولاً شبیه مرورگر یا یک برگه‌ی سفید است.
3. روی آن **دوبار کلیک** کنید.
4. اگر پرسید با چه برنامه‌ای باز شود، **Google Chrome**، **Microsoft Edge** یا **Firefox** را انتخاب کنید.
5. بازی باز می‌شود. تمام.

این روش برای بازی کاملاً کافی است. فقط دکمه‌ی «کپی PGN» در بعضی مرورگرها ممکن است برای امنیت، هنگام بازکردن مستقیم فایل کار نکند؛ بقیه‌ی بازی بدون مشکل کار می‌کند.

### روش ۲: اجرای مطمئن با یک کلیک در ویندوز (فقط اگر روش اول را نخواستید)

این روش هم نیازی به برنامه‌نویسی ندارد، اما از شما می‌خواهد یک دستور را کپی کنید:

1. داخل پوشه‌ی پروژه، در یک جای خالی **Shift را نگه دارید و راست‌کلیک** کنید.
2. گزینه‌ی **Open in Terminal** یا **باز کردن در ترمینال** را بزنید.
3. این خط را عیناً کپی و Paste کنید، سپس Enter بزنید:

   ```text
   python -m http.server 8000
   ```

4. مرورگر را باز کنید و این آدرس را وارد کنید:

   ```text
   http://localhost:8000
   ```

5. برای بستن سرور، به همان پنجره‌ی مشکی برگردید و کلیدهای **Ctrl + C** را بزنید.

اگر پیام داد که `python` پیدا نشد، روش ۱ را استفاده کنید؛ برای این بازی لازم نیست چیزی نصب کنید.

## آموزش بازی، قدم‌به‌قدم

1. **سفید شروع می‌کند.** روی یک مهره‌ی سفید کلیک/لمس کنید.
2. خانه‌هایی که مهره می‌تواند به آن‌ها برود با دایره یا قاب رنگی روشن می‌شوند.
3. روی یکی از آن خانه‌ها کلیک کنید تا حرکت انجام شود.
4. حالا نوبت بازیکن سیاه است؛ همان کار را برای مهره‌های سیاه انجام دهید.
5. اگر شاه در خطر باشد، خانه‌ی شاه با هشدار قرمز نمایش داده می‌شود و فقط حرکت‌هایی که او را نجات بدهند قابل انتخاب‌اند.
6. اگر پیاده را به آخرین ردیف برسانید، پنجره‌ای باز می‌شود. روی مهره‌ای که می‌خواهید پیاده به آن تبدیل شود کلیک کنید؛ معمولاً **وزیر** بهترین انتخاب است.
7. بازی با کیش‌ومات، پات، تمام‌شدن زمان یا دکمه‌ی «پایان بازی» تمام می‌شود.

### دکمه‌های مهم روی صفحه

| دکمه | کاربرد |
|---|---|
| **بازی جدید** | همه‌چیز را از چیدمان اول شطرنج شروع می‌کند. |
| **پایان بازی** | بازیکنی که نوبتش است را تسلیم می‌کند. |
| **راهنما** | یک حرکت پیشنهادی را روی صفحه با ستاره نشان می‌دهد. |
| **↶ بازگشت** | آخرین حرکت را برمی‌گرداند. میانبر کیبورد: `Ctrl + Z` یا `Cmd + Z`. |
| **⟳ / چرخش** | صفحه را از دید بازیکن سیاه می‌چرخاند. میانبر کیبورد: `F`. |
| **قاب چهارگوش** | حالت تمرکز را فعال می‌کند تا صفحه نزدیک‌تر دیده شود. |
| **خورشید** | بین نور زمردی و نور کهربایی جابه‌جا می‌شود. |
| **بلندگو** | صدای کوتاه حرکت مهره‌ها را خاموش/روشن می‌کند. |
| **کپی PGN** | متن استاندارد حرکت‌های بازی را کپی می‌کند. |

## اگر بازی را از گیت‌هاب دانلود کرده‌اید

نیازی نیست Git یا GitHub را یاد بگیرید. فقط این کارها را انجام دهید:

1. در صفحه‌ی پروژه در GitHub، روی دکمه‌ی سبز **Code** بزنید.
2. گزینه‌ی **Download ZIP** را انتخاب کنید.
3. بعد از دانلود، روی فایل ZIP راست‌کلیک کنید و **Extract All** یا «استخراج همه» را بزنید.
4. پوشه‌ی استخراج‌شده را باز کنید.
5. طبق «روش ۱» بالا، روی `index.html` دوبار کلیک کنید.

## اگر می‌خواهید بازی را برای دیگران روی اینترنت قرار دهید (اختیاری)

این بخش فقط برای زمانی است که یک لینک عمومی می‌خواهید. برای بازی روی کامپیوتر خودتان لازم نیست.

1. وارد حساب GitHub خود شوید یا در [github.com](https://github.com) یک حساب رایگان بسازید.
2. یک مخزن (Repository) جدید بسازید؛ نام پیشنهادی: `shahmat`.
3. در صفحه‌ی مخزن روی **Add file** و سپس **Upload files** بزنید.
4. سه فایل `index.html`، `styles.css` و `app.js` را از پوشه‌ی پروژه به صفحه بکشید.
5. دکمه‌ی سبز **Commit changes** را بزنید.
6. وارد تب **Settings** مخزن شوید، در منوی سمت چپ **Pages** را انتخاب کنید.
7. در بخش **Build and deployment**، مقدار **Source** را روی `Deploy from a branch` بگذارید.
8. شاخه‌ی `main` و پوشه‌ی `/(root)` را انتخاب کنید و **Save** را بزنید.
9. حدود ۱ تا ۳ دقیقه صبر کنید و صفحه را یک‌بار تازه‌سازی کنید. GitHub یک لینک شبیه این می‌دهد:

   ```text
   https://نام-کاربری-شما.github.io/shahmat/
   ```

10. این لینک را می‌توانید برای هر کسی بفرستید؛ او هم بدون نصب چیزی بازی را در مرورگر باز می‌کند.

## فایل‌های پروژه

```text
index.html   ← صفحه و اجزای ظاهری بازی
styles.css   ← رنگ، مدل ظاهری سه‌بعدی، چیدمان و واکنش‌گرایی
app.js       ← منطق بازی شطرنج، ساعت، حرکات و دکمه‌ها
README.md    ← همین راهنما
```

اگر بعداً خواستید رنگ‌ها، نام بازیکن یا زمان بازی را عوض کنید، نیازی نیست از ابتدا چیزی بسازید؛ فقط همان فایل‌ها را باید ویرایش کنید. اما برای اجرای نسخه‌ی فعلی، **هیچ‌کدام را تغییر ندهید**.
